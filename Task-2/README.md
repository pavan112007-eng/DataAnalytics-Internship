# Objective
The objective of this task was to create meaningful visualizations and build an interactive dashboard that communicates business insights through effective data storytelling using Power BI.

# Dataset Used
Sales Dataset (`sales.csv`)

The dataset contains product-related information such as:
- Product Name
- Category
- Discounted Price
- Actual Price
- Discount Percentage
- Rating
- Rating Count
- Product Reviews

---

# Tools Used
- Power BI Desktop
- Microsoft Excel (for reference)
- GitHub

---

# Data Preparation
Before creating visualizations, the dataset was cleaned and transformed using Power Query in Power BI.

### Data Cleaning Steps:
- Removed currency symbols (₹) from price columns.
- Removed commas from numeric fields.
- Converted price columns into decimal numbers.
- Converted discount percentage into numeric format.
- Converted rating count into whole numbers.
- Verified and corrected data types.
- Removed inconsistencies in the dataset.

---

# Dashboard Visualizations

## 1. KPI Cards
Created KPI cards to display:
- Total Products
- Average Rating
- Average Discount Percentage

## 2. Products by Category
Used a clustered bar chart to analyze product distribution across categories.

## 3. Average Rating by Category
Created a column chart to compare category-wise average ratings.

## 4. Average Discount by Category
Visualized discount patterns across product categories.

## 5. Category Distribution
Used a pie chart to show the proportion of products in each category.

## 6. Product Details Table
Created a detailed table displaying:
- Product Name
- Rating
- Discount Percentage
- Discounted Price
- Actual Price

## 7. Interactive Slicer
Added category filters to make the dashboard interactive.

# Key Business Insights

- Certain categories contain a higher number of products than others.
- Most product categories maintain good average ratings.
- Several products offer significant discounts.
- Customer ratings help identify highly preferred product categories.
- Interactive filtering allows detailed category-level analysis.
