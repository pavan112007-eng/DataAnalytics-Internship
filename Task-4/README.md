# Task 4 - Interactive Dashboard Design using Power BI

## Internship
Data Analyst Internship

---

# Objective

The objective of this task was to design and develop an interactive Power BI dashboard that enables users to analyze customer behavior, deposit subscriptions, account balances, and campaign performance using the Bank Marketing Dataset.

The dashboard provides meaningful business insights through data visualization and interactive filtering.

---

# Dataset Used

**Bank Marketing Dataset** (`bank.csv.xls`)

The dataset contains customer-related information such as:

- Age
- Job
- Marital Status
- Education
- Account Balance
- Housing Loan
- Personal Loan
- Contact Type
- Campaign Contacts
- Month
- Deposit Subscription (Yes/No)

### Target Variable

**Deposit**

Indicates whether a customer subscribed to a term deposit.

# Key Business Insights

- The dashboard contains over **11,000 customers**.
- Approximately **5,000 customers subscribed** to term deposits.
- The overall **deposit rate is 47.38%**.
- Management and blue-collar job categories contribute significantly to deposit subscriptions.
- Married customers represent the largest customer segment.
- Retired customers maintain the highest average account balances.
- Deposit subscriptions vary across education levels and months.
- Customer financial position influences campaign success.
